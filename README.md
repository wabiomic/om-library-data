# Om Open Library data

Versioned, machine-built pathway and annotation sets for human and mouse genes, proteins and metabolites,
built only from sources that allow commercial redistribution. Each folder is one release; `manifest.json`
lists every file with its sha256 and every source with its license. See ATTRIBUTION.txt.
Served through jsDelivr. Pattern: https://cdn.jsdelivr.net/gh/wabiomic/om-library-data@vYYYY.MM.DD/YYYY.MM.DD/manifest.json
